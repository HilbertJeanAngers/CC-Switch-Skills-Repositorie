# Notion Course Notes

## Overview

维护和整理用户的 Notion 笔记。用户最常见的三类需求（本技能都覆盖）：

1. **网课图片补注释**：页面里堆了一堆课程截图，自动找出没配文字的裸图，识别图中知识点，按风格在每张图前插入注释。
2. **AI 知识补齐**：用户从 AI 处复制一段知识点到 Notion，要求补齐/展开成结构化笔记（简介、速查、示例、路线等）。补充适度即可，不要堆砌大量代码段。
3. **已有笔记布局整理**：把页面重排成知识库结构；**一级标题一律做成可折叠标题，二级/三级标题按长度适当折叠**，避免页面过长影响观看。

风格与流程分离——流程固定，风格与折叠规则集中在 `references/STYLE.md`，改一次永久生效。

## 三条核心工作流（按用户意图选）

| 用户说的话 | 走哪条 |
|---|---|
| "给 XX 笔记的图片补注释 / 网课图片加注释" | **A. 图片补注释** → 下方 `### 步骤 0~6` |
| "把这段知识补到 Notion / 补齐 XX 笔记" | **B. AI 知识补齐** → 见下 |
| "XX 笔记太乱 / 整理布局 / 知识点折叠" | **C. 布局整理** → 见下 |

> 三条都可能组合出现。无论哪条，**改动前先备份**（步骤 1）、**改完复验 + 清理**（步骤 6）都适用。

### 工作流 B：AI 知识补齐
1. 备份目标页面。
2. 读现有内容，判断是"一段待展开的零散知识"还是"已成型的笔记"。
3. 按知识库结构补齐：简介 / 安装或准备 / 核心概念速查 / 少量精选示例 / 学习路线（按领域裁剪，不必凑齐）。
4. **补充适度**：代码示例给够用的即可（通常 1~2 段能说明问题），不要为每个小的点都写一大段代码把页面撑长。
5. 套用折叠规则（见下）：一级标题必须折叠，二级/三级标题按长度适当折叠。
6. 复验 + 清理。

### 工作流 C：已有笔记布局整理
1. 备份目标页面。
2. 读完整块结构（注意递归进 `has_children` 的子块，表格/已有折叠标题都有子块）。
3. 按主题重排为清晰层级，套用折叠规则（见下）。
4. 复验 + 清理。

### 折叠规则（B、C 及整理类操作必用；详见 STYLE.md）
- **一级标题（heading_1）必须折叠**：一律做成可折叠标题，`is_toggleable: true`，内容放 `children`。这是硬性要求，不管长短。
- **二级/三级标题（heading_2 / heading_3）按长度适当处理**：内容长的（子块多 / 多段代码 / 多张图）做成可折叠；短的直接平铺，不必强行折叠。
- **折叠标题只写知识点本身的名字**，不要加"（点击展开全文）""（点开查看）"这类提示性废话。

## 前置条件

1. 环境变量 `NOTION_TOKEN` 已设置为 Notion 个人访问令牌（`ntn_` 开头）。
   - 若未设置，提示用户：`$env:NOTION_TOKEN='ntn_xxx'`（临时）或 `setx NOTION_TOKEN 'ntn_xxx'`（永久，重开终端生效）。
2. Python 3 + Pillow（`pip install Pillow`）。所有脚本用标准库调 API，无其他依赖。

脚本目录：`<skill>/scripts/`。运行前把该目录加入工作路径或用绝对路径调用。

## 工作流

### 步骤 0：确认目标与范围（工作流 A 专用）
先问清/确认两件事（用户说"整理 XX 笔记"时通常已给出页面名）：
- 目标页面（标题关键词即可）
- 补注释的范围：全部裸图，还是仅指定的几张（用户可能只要改某一张）

> 工作流 B、C 的目标和范围判断见各自的章节，不必走这里的裸图范围确认。

### 步骤 1：备份
```bash
python scripts/backup_page.py <页面ID>
```
改动前必须留底，产出 `notion_backup_<id>_<日期>.json`。

### 步骤 2：分析页面结构，找裸图
```bash
python scripts/analyze_page.py <页面标题关键词>
```
- 输出每张图的编号、前置文字、是否裸图（`<<< 裸图·缺注释`）。
- 若匹配到多个页面，让用户用完整标题或页面 ID 重试。
- 记住输出的 `页面ID`（后续步骤要用）。

### 步骤 3：下载图片并识别内容
```bash
python scripts/prepare_images.py            # 全部裸图
python scripts/prepare_images.py 3 5 8      # 或只下指定编号
```
- 用看图工具查看 `%TEMP%/notion_notes_imgs/sheet_*.jpg` 拼版（带编号）。
- 字看不清就查看同目录 `zoom_*.png` 单张放大图。
- 逐张记下"编号 → 知识点短语"。短语照图里的标题/核心概念命名，简短不加句号。

### 步骤 4：确认风格
```bash
python scripts/insert_caption.py --config
```
读取当前风格（默认：普通段落、无前后缀）。若用户本次有特殊要求，可临时覆盖，不改配置。

### 步骤 5：逐张插入注释
```bash
python scripts/insert_caption.py <页面ID> <图片编号> "<注释文字>"
```
- 对每张需要补的图执行一次。脚本自动定位图片所在父块，把注释插在图正前方。
- 内置防重复：若图前已有相同文字则跳过。
- 遇到 `unsupported` 块保持原样，不要动。

### 步骤 6：复验与收尾
- 重新运行 `analyze_page.py` 确认裸图已消除、注释顺序正确。
- 清理临时图片目录 `%TEMP%/notion_notes_imgs/` 和 `%TEMP%/notion_page_analysis.json`。
- 告知用户备份文件路径和恢复方法。

## 改风格与规则（用户最关心）

注释风格、折叠规则、补充力度全部集中在 `references/STYLE.md`：
- **一句话改**：用户说"把注释风格改成 XXX"或"以后折叠标题别写废话" → 编辑 STYLE.md 对应段落 → 之后所有页面生效。
- **自己改**：直接编辑 STYLE.md，纯文本。
- **临时覆盖**：仅本次用不同风格，不改文件。
详见 `references/STYLE.md`（含注释风格三行配置 + 折叠规则 + 补充力度）。

## 恢复

- 撤销归档：`python scripts/restore_page.py <页面ID...>` 或 `--from-archive`。
- 内容有损：用 `backup_page.py` 产出的 JSON 手工重建。
